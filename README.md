Python/SQLite Capstone

This repository also includes a separate Python and SQLite capstone project: **Bookstore Manager**.

The Bookstore Manager is a menu-driven command-line application developed in Python using SQLite for data storage. It allows users to add, update, delete, and search book records, demonstrating basic database management and CRUD functionality.

Skills demonstrated
- Python programming
- SQLite database integration
- CRUD operations
- Command-line application development
- Structured data handling
