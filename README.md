# Ebookstore Manager

A Python and SQLite command-line application for managing bookstore records.

## Overview
This project was developed as a capstone task to demonstrate database-driven application development in Python. The application stores book information in a SQLite database and allows users to add, update, delete, and search book records through a menu-driven interface.

## Features
- Add new book records
- Update existing book information
- Delete books from the database
- Search books by title or author
- Store and retrieve data using SQLite

## Technologies Used
- Python
- SQLite3

## Skills Demonstrated
- Python programming
- SQLite database integration
- CRUD operations
- Command-line application development
- Structured data handling
